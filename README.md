# Hi, I'm Andrey Helldar 👋

Open-source maintainer building tools for the PHP and Laravel ecosystem.
I focus on localization, deployment automation, databases, caching,
telemetry, and release workflows.

I lead [Laravel Lang](https://github.com/Laravel-Lang) and maintain projects
across [The Dragon Code](https://github.com/TheDragonCode), [The Dragon Skills](https://github.com/TheDragonSkills) and [Kvede Bot](https://kvede.com).
Laravel Lang provides translations for
[128 languages](https://github.com/Laravel-Lang/lang).

## Selected Work

- [Laravel Lang](https://github.com/Laravel-Lang) — localization infrastructure
  for Laravel ecosystem products and third-party packages.
- [Deploy Operations](https://github.com/TheDragonCode/laravel-deploy-operations) —
  run application-defined operations during Laravel deployments.
- [Database Data Dumper](https://github.com/TheDragonCode/laravel-data-dumper) —
  include selected table data in Laravel schema dumps.
- [Migrate DB](https://github.com/TheDragonCode/migrate-db) —
  transfer data between databases.
- [The Dragon Skills](https://github.com/TheDragonSkills) —
  reusable skills for AI agents.
- [Kvede Bot](https://kvede.com) —
  Telegram chat management and analytics.

More Laravel and PHP packages are available at
